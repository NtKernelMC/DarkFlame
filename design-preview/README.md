# Дизайн вкладки «Поливалка»

Баннер скрывается только во вкладке «Поливалка»; на остальных шести вкладках он остаётся. Навигация и содержимое «Поливалки» подняты в освободившееся место.

Управление и обновление скрипта находятся слева. Справа — «Обзор», «Светофоры и метки» и «Редактор меток». Шапка с записью телеметрии и навигация закреплены. Список меток и содержимое разделов прокручиваются независимо. Длинный статус полностью доступен при наведении.

Изменены Client/gui.cpp, Client/plow_bot.cpp и UI-проверки Tests/plow_marks_test.cpp, Tests/run_plow_marks_test.cmd. Изображения в Client/assets сохранены. Исходные gui.cpp и plow_bot.cpp до правок лежат в original.

Собранный клиент: ../bin/Release/x86/DarkFlameClient.dll. Для применения закройте игру и загрузчик, сохраните копию текущей DarkFlameClient.dll в корне DarkFlame-new, замените её новой DLL и запустите приложение снова.

Проверены реальные кадры ImGui/Direct3D при 1200×740, 1280×720, 1024×768 и 1370×900. UI-тест проверяет запуск бота, запись/остановку телеметрии, обновление скрипта, отключение недоступных действий, светофоры, создание и редактор меток, а также отсутствие баннера только в «Поливалке». Файлы PlowMarks в renders — тестовые данные.

Снимки: renders/overview_1200x740.png, renders/editor_1200x740.png. Воспроизведение проверки: Tests/run_plow_marks_test.cmd после сборки клиента Release|Win32. Параметр --build-only компилирует тест без запуска Direct3D.

Светофоры и создание меток объединены в два блока одной вкладки. Кнопка открытия редактора убрана. Скорость и размер метки используют общий компонент Client/ui_widgets.h: фиолетовая дорожка, круглый бегунок и значение справа. Снимок: renders/combined_1200x740.png.
